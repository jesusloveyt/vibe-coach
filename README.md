# Vive Coach

**AI와 대화하며 프로그램을 만드는 경험을 돕는 학습 가이드 모음입니다.**

코딩을 처음 접하는 분부터 직접 코드를 수정하며 배우고 싶은 분까지, 자신의 경험에 맞는 과정을 선택할 수 있도록 만들고 있습니다. 원하는 것을 말로 설명하고, 실행된 결과를 확인하고, 개선을 요청하는 과정을 통해 AI와 함께 작업하는 방법을 익힙니다.

코드를 완성하는 것과 함께 **내 의도를 전달하고, AI가 만든 결과를 확인하는 힘**을 기르는 것이 목표입니다. AI도 요청을 잘못 이해하거나 실수할 수 있으므로, 결과를 살펴보고 다시 요청하는 과정도 학습에 포함됩니다.

## 처음이라면 여기서 시작하세요

1. **도구 준비하기:** [설치와 계정 연결 안내](./setup/README.md)를 따라 VS Code와 AI 코딩 도구를 준비합니다. Codex와 Claude Code 중 하나만 선택하면 됩니다.
2. **과정 선택하기:** 아래에서 자신에게 맞는 과정을 고릅니다. 코딩 경험이 없다면 Starter부터 시작하세요.
3. **AI와 함께 만들기:** 선택한 과정의 안내에 따라 요청하고, 결과를 열어 보고, 원하는 방향으로 바꿔 봅니다.

이미 VS Code에서 AI와 대화할 수 있다면 도구 준비는 건너뛰어도 됩니다. 학습을 위해 이 저장소를 다운로드하거나 GitHub 계정을 만들 필요는 없습니다.

## 나에게 맞는 과정 고르기

| 과정 | 이런 분을 위한 과정입니다 | 진행 방식 | 시작하기 |
| --- | --- | --- | --- |
| **Starter** | 코딩 경험 없이 첫 프로그램을 만들어 보고 싶은 분 | AI가 코드를 작성하고, 학습자는 요청·결과 확인·수정을 경험합니다. | [Starter 안내](./starter/README.md) |
| **Calculator** | 파일의 일부 내용을 직접 바꾸며 배우고 싶은 분 | 버튼의 `?`를 숫자로 바꾸고 AI의 검토를 받습니다. 원하면 계산 로직 수정도 연습합니다. | [Calculator 안내](./solutions/calculator/README.md) |

**Starter**에서는 사칙 연산 계산기 또는 자기 소개 웹사이트를 만듭니다. 코드 문법을 먼저 공부하거나 빈칸을 채울 필요 없이, AI에게 원하는 것을 말하는 데서 시작합니다. 결과물은 자신의 연습 폴더 아래 `codes`에 저장됩니다.

**Calculator**에서는 AI가 준비한 계산기의 숫자 표시를 직접 수정하고, 저장 → 검토 요청 → 실행 확인을 경험합니다. 기본 실습에는 문법 지식이 필요하지 않습니다. 완료 후 선택하는 로직 실습에서는 덧셈·뺄셈을 자세한 안내에 따라 수정하고, 곱셈·나눗셈은 직접 작성한 뒤 리뷰를 받습니다.

Starter 이후의 주제별 학습 과정은 `solutions/`에 모읍니다. 원하는 주제를 선택해 시작할 수 있으며, Calculator는 Starter를 마치지 않아도 참여할 수 있습니다.

## 어떤 방식으로 배우나요?

**요청하기 → 결과 확인하기 → 수정 요청하기**를 반복합니다.

예를 들어 “계산기를 만들어 줘”라고 요청하고, 브라우저에서 `2 + 3 = 5`가 되는지 확인합니다. 이어서 “숫자 버튼을 더 크게 해 줘” 또는 “거듭제곱 기능을 추가해 줘”라고 요청하며 원하는 결과에 가까워지는 경험을 합니다.

각 과정에는 다음 자료를 담습니다.

- **README.md:** 학습자가 따라갈 순서와 실행 방법
- **AGENTS.md:** AI가 학습자를 안내할 때 따를 코칭 지침
- **대화 예시:** 실제 요청과 수정 과정을 참고할 수 있는 기록

미리 대화를 살펴보고 싶다면 [계산기 만들기](./starter/4칙계산기-dialogues.md)와 [자기 소개 웹사이트 만들기](./starter/자기소개서-dialogues.md)를 읽어 보세요.

직접 수정하는 실습은 [Calculator 대화 예시](./solutions/calculator/dialogues.md)에서 숫자 표시 수정부터 선택형 로직 실습까지 살펴볼 수 있습니다.

## 개발자 여러분, 새로운 학습 가이드 및 예제를 만들어 주세요

**프로그램을 직접 개발하고 문제를 해결해 본 능력자 여러분의 참여를 기다립니다. 
여러분의 개발 경험을 초보자가 AI와 함께 따라갈 수 있는 학습 과정으로 만들어 `solutions/`에 추가해 주세요.**

이 프로젝트에서 기여받고 싶은 핵심은 **프로그램을 완성하기까지의 안내와 바이브 코칭 지침**입니다. 무엇부터 요청할지, 어떤 순서로 기능을 더할지, 결과를 어떻게 확인할지에 여러분의 경험을 담아 주세요. 문법 설명을 최소화하면서도 학습자가 직접 결과를 확인하고 개선할 수 있는 다양한 주제를 환영합니다.

### 어떤 예제를 기여할 수 있나요?

- 할 일 관리, 독서 기록, 가계부처럼 일상에서 사용할 수 있는 프로그램
- 학습자가 화면의 문구나 숫자를 직접 바꾸며 변화를 확인하는 실습
- AI가 기능을 단계적으로 추가하고 학습자가 매 단계 결과를 확인하는 과정
- 데이터 저장, 외부 서비스 연동, 배포 등 개발 경험을 넓혀 주는 과정

### 이렇게 참여해 주세요

1. 만들 프로그램과 학습 목표를 정하고 `solutions/<주제명>/` 폴더를 만듭니다.
2. 아래 세 가지 문서를 작성합니다. [Starter](./starter/README.md)의 구성과 [코칭 지침](./starter/AGENTS.md), 주제별 예제인 [Calculator](./solutions/calculator/README.md)와 [Calculator 코칭 지침](./solutions/calculator/AGENTS.md)을 참고할 수 있습니다.

| 문서 | 담아 주세요 |
| --- | --- |
| `README.md` | 학습 대상, 완성 목표, 준비 사항과 비용, 진행 순서, 실행·확인 방법 |
| `AGENTS.md` | AI의 단계별 코칭 방식, 학습자가 직접 할 일, 막혔을 때의 도움, 프롬프트 개선 조언 |
| `dialogues.md` | 요청 → 구현 → 확인 → 수정으로 이어지는 대화 예시 |

3. 별도의 연습 폴더에서 안내를 직접 따라가며, AI와 함께 결과물을 완성할 수 있는지 확인합니다.
4. 학습 대상, 완성할 결과물, 직접 확인한 내용을 적어 Pull Request를 보내 주세요. 관리자가 검토한 뒤 반영합니다.

이 저장소에는 Markdown 안내와 콘텐츠를 기여합니다. 코드 예시는 문서에 넣을 수 있으며, 실제 프로그램 코드 파일은 학습자의 연습 폴더에서 생성하도록 안내해 주세요.

주제나 구성에 대한 논의가 필요하다면 먼저 Issue로 제안해 주세요. 기존 안내의 오류 수정과 학습 중 막힌 부분에 대한 피드백도 환영합니다. 세부 기여 가이드는 준비 중이며, 현재는 위 절차를 기준으로 참여하시면 됩니다.
