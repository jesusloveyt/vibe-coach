# Vive Coach

**AI와 대화하며 프로그램을 만드는 경험을 돕는 학습 가이드 모음입니다.**

코딩을 처음 접하는 분부터 직접 코드를 수정하며 배우고 싶은 분까지, 자신의 경험에 맞는 과정을 선택할 수 있도록 만들고 있습니다. 원하는 것을 말로 설명하고, 실행된 결과를 확인하고, 개선을 요청하는 과정을 통해 AI와 함께 작업하는 방법을 익힙니다.

코드를 완성하는 것과 함께 **내 의도를 전달하고, AI가 만든 결과를 확인하는 힘**을 기르는 것이 목표입니다. AI도 요청을 잘못 이해하거나 실수할 수 있으므로, 결과를 살펴보고 다시 요청하는 과정도 학습에 포함됩니다.

## 처음이라면 여기서 시작하세요

1. **도구 준비하기:** [설치와 계정 연결 안내](./setup/README.md)를 따라 VS Code와 AI 코딩 도구를 준비합니다. Codex와 Claude Code 중 하나만 선택하면 됩니다.
2. **과정 선택하기:** 아래에서 자신에게 맞는 과정을 고릅니다. 코딩 경험이 없다면 Starter부터 시작하세요.
3. **AI와 함께 만들기:** 선택한 과정의 안내에 따라 요청하고, 결과를 열어 보고, 원하는 방향으로 바꿔 봅니다.

이미 VS Code에서 AI와 대화할 수 있다면 도구 준비는 건너뛰어도 됩니다. 학습을 위해 이 저장소를 다운로드하거나 GitHub 계정을 만들 필요는 없습니다.

## 나에게 맞는 과정 고르기

| 과정 | 이런 분을 위한 과정입니다 | 진행 방식 | 시작하기 |
| --- | --- | --- | --- |
| **Starter** | 코딩 경험 없이 첫 프로그램을 만들어 보고 싶은 분 | AI가 코드를 작성하고, 학습자는 요청·결과 확인·수정을 경험합니다. | [Starter 안내](./starter/README.md) |
| **Hands-on** | 코드를 조금씩 직접 바꾸며 배우고 싶은 분 | 작은 코드 수정과 실행을 통해 프로그램의 동작을 이해합니다. | 준비 중 |

**Starter**에서는 사칙 연산 계산기 또는 자기 소개 웹사이트를 만듭니다. 코드 문법을 먼저 공부하거나 빈칸을 채울 필요 없이, AI에게 원하는 것을 말하는 데서 시작합니다. 결과물은 자신의 연습 폴더 아래 `codes`에 저장됩니다.

**Hands-on**은 직접 코드를 수정하는 경험을 더하는 과정으로 준비하고 있습니다. 안내가 완성되면 이곳에서 연결합니다.

## 어떤 방식으로 배우나요?

**요청하기 → 결과 확인하기 → 수정 요청하기**를 반복합니다.

예를 들어 “계산기를 만들어 줘”라고 요청하고, 브라우저에서 `2 + 3 = 5`가 되는지 확인합니다. 이어서 “숫자 버튼을 더 크게 해 줘” 또는 “거듭제곱 기능을 추가해 줘”라고 요청하며 원하는 결과에 가까워지는 경험을 합니다.

각 과정에는 다음 자료를 담습니다.

- **README.md:** 학습자가 따라갈 순서와 실행 방법
- **AGENTS.md:** AI가 학습자를 안내할 때 따를 코칭 지침
- **대화 예시:** 실제 요청과 수정 과정을 참고할 수 있는 기록

미리 대화를 살펴보고 싶다면 [계산기 만들기](./starter/4칙계산기-dialogues.md)와 [자기 소개 웹사이트 만들기](./starter/자기소개서-dialogues.md)를 읽어 보세요.
