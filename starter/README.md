# AI와 첫 프로그램 만들기

코딩을 몰라도 괜찮습니다. 만들고 싶은 것을 말하면 AI가 코드를 작성합니다. 여러분은 결과를 열어 보고, 바꾸고 싶은 점을 말하면 됩니다.

**요청하기 → 결과 확인하기 → 수정 요청하기**, 이 세 가지를 함께 해 봅니다.

만들 수 있는 프로그램은 두 가지입니다.

- **계산기:** 숫자 버튼으로 덧셈, 뺄셈, 곱셈, 나눗셈을 합니다.
- **자기 소개 웹사이트:** 내 소개와 관심사를 담은 페이지를 만듭니다. 사진은 없어도 됩니다.

무엇을 만들지 고민된다면, 준비할 자료가 없는 **계산기**부터 시작해 보세요.

## 시작하기 전에

이 안내는 **VS Code에서 AI와 대화할 수 있는 상태**부터 시작합니다. 사용하는 AI 도구는 파일을 만들고 수정할 수 있어야 합니다.

아직 설치하거나 로그인하지 않았다면 [처음 시작하는 분을 위한 설치와 준비](../setup/README.md)를 먼저 따라 하세요. Codex와 Claude Code 중 하나를 선택해 계정 연결까지 진행할 수 있습니다.

이 저장소를 다운로드하거나 GitHub 계정을 만들 필요는 없습니다. 아래에서 안내 파일 하나만 복사합니다.

## 1. 연습할 폴더 열기

**이미 VS Code에 연습할 폴더를 열어 두었다면 2단계로 넘어가세요.**

1. 컴퓨터에서 찾기 쉬운 곳에 `my-first-app`이라는 폴더를 만듭니다.
2. VS Code를 엽니다.
3. 위쪽 메뉴에서 **파일 → 폴더 열기**를 누르고, 방금 만든 폴더를 선택합니다.

VS Code 왼쪽 파일 목록에 `my-first-app`이 보이면 준비된 것입니다.

> **[스크린샷 1 자리 · 연습 폴더 열기]**  
> VS Code의 ‘파일 → 폴더 열기’ 메뉴와, 연 뒤 왼쪽에 표시되는 `my-first-app` 폴더를 보여 주세요. 두 화면을 나란히 배치해도 됩니다.
<!-- 이미지 준비 후 위 자리표시자를 교체: ![VS Code에서 연습 폴더를 연 모습](./images/01-open-folder.png) -->

## 2. AI에게 줄 안내 파일 준비하기

`AGENTS.md`는 **AI가 여러분을 어떻게 도와야 하는지 적은 안내 파일**입니다. 내용을 이해하거나 외울 필요 없이 그대로 복사하면 됩니다.

1. [안내 파일 AGENTS.md](./AGENTS.md)를 엽니다.
2. 문서의 내용 전체를 복사합니다. GitHub에서는 `Raw` 버튼으로 글자만 있는 화면을 열어 복사할 수 있습니다.

> **[스크린샷 2 자리 · 안내 내용 복사하기]**  
> GitHub의 `AGENTS.md` 화면에서 `Raw` 버튼 위치를 표시해 주세요.
<!-- 이미지 준비 후 위 자리표시자를 교체: ![AGENTS.md 원문을 여는 Raw 버튼 위치](./images/02-copy-guide.png) -->

3. VS Code로 돌아옵니다. 왼쪽 파일 목록에서 연습 폴더에 **새 파일**을 만들고, 이름을 `AGENTS.md`로 입력합니다.
4. 복사한 내용을 붙여 넣고 저장합니다. Windows는 **Ctrl+S**, Mac은 **Cmd+S**입니다.

왼쪽 파일 목록에 `AGENTS.md`가 보이고, 파일을 열었을 때 복사한 글이 보이면 됩니다.

> **[스크린샷 3 자리 · 안내 파일 저장하기]**  
> VS Code 왼쪽의 `my-first-app` 아래 `AGENTS.md`와, 오른쪽에 붙여 넣은 안내 내용을 함께 보여 주세요. 파일 이름을 강조해 주세요.
<!-- 이미지 준비 후 위 자리표시자를 교체: ![연습 폴더에 저장한 AGENTS.md](./images/03-save-guide.png) -->

## 3. AI에게 만들 것을 말하기

VS Code에서 사용하는 AI의 대화창을 열고, 아래 문장을 복사해서 보내세요.

```text
나는 완전 초보자다. 현재 폴더의 AGENTS.md 파일을 읽고, 문서의 지침에 따라 나를 안내해 줘.
```

AI가 무엇을 만들지 물으면 **“계산기를 만들어 줘”** 또는 **“자기 소개 웹사이트를 만들어 줘”**라고 답하세요.

> **[스크린샷 4 자리 · 첫 요청 보내기]**  
> AI 대화창에 위 요청을 보낸 모습과, AI가 두 프로그램 중 하나를 고르도록 안내하는 답변을 보여 주세요. 사용한 AI 도구 이름을 캡션에 적어 주세요.
<!-- 이미지 준비 후 위 자리표시자를 교체: ![AI에게 안내 파일을 읽고 시작해 달라고 요청한 대화](./images/04-first-request.png) -->

자기 소개 웹사이트를 고르면 AI가 이름이나 별명, 소개, 관심사를 물어봅니다. 준비한 내용이 없으면 **“예시 내용으로 만들어 줘”**라고 해도 됩니다. 사진을 넣고 싶다면 연습 폴더에 복사한 뒤 AI에게 파일 이름을 알려 주세요.

이제 AI가 프로그램을 만들고 저장할 때까지 기다립니다. 코드를 직접 복사할 필요는 없습니다.

## 4. 만든 프로그램 열어 보기

AI가 연습 폴더 안에 `codes` 폴더를 만들고 결과물을 저장합니다. **`codes` 폴더는 직접 만들지 않아도 됩니다.**

| 선택한 프로그램 | 열어 볼 파일 |
| --- | --- |
| 계산기 | `codes/calculator.html` |
| 자기 소개 웹사이트 | `codes/myweb.html` |

선택한 프로그램의 파일만 생기는 것이 정상입니다.

1. 컴퓨터의 **파일 탐색기**에서 AI가 알려 준 연습 폴더를 엽니다. Mac에서는 **Finder**를 사용합니다.
2. 그 안의 `codes` 폴더를 엽니다.
3. `calculator.html` 또는 `myweb.html`을 두 번 클릭합니다.

Chrome이나 Edge 같은 **브라우저(인터넷 페이지를 보는 프로그램)**에서 결과가 열립니다. 다른 프로그램에서 열린다면 파일을 마우스 오른쪽 버튼으로 누르고 **연결 프로그램**에서 브라우저를 선택하세요.

> **[스크린샷 5 자리 · 결과 파일 열기]**  
> 파일 탐색기의 `my-first-app → codes` 위치와 `calculator.html` 파일을 보여 주세요. 두 번 클릭할 파일을 표시해 주세요.
<!-- 이미지 준비 후 위 자리표시자를 교체: ![codes 폴더에서 calculator.html을 여는 위치](./images/05-open-result.png) -->

계산기를 만들었다면 **2 → + → 3 → =**을 눌러 **5**가 나오는지 확인하세요. 자기 소개 웹사이트라면 소개 글이 잘 보이는지 살펴보세요. 확인한 결과를 AI에게 알려 주세요.

> **[스크린샷 6 자리 · 첫 결과 확인하기]**  
> 브라우저에서 계산기로 `2 + 3 = 5`를 확인한 화면을 보여 주세요.
<!-- 이미지 준비 후 위 자리표시자를 교체: ![계산기에서 2 더하기 3의 결과를 확인한 모습](./images/06-check-result.png) -->

## 5. 원하는 대로 바꿔 보기

AI 대화창으로 돌아가 바꾸고 싶은 점을 말해 보세요. 아래에서 하나를 골라 보내도 됩니다.

```text
숫자 버튼의 글씨를 더 크게 해 줘.
```

```text
배경색을 연한 파란색으로 바꿔 줘.
```

계산기에 기능을 더하고 싶다면 이렇게 요청할 수도 있습니다.

```text
거듭제곱 연산 ^ 도 추가해 줘.
```

AI가 수정을 마치면 브라우저로 돌아가 **새로고침 버튼 ↻**을 누르세요. Windows에서는 **F5**로도 새로고침할 수 있습니다.

> **[스크린샷 7 자리 · 수정한 결과 확인하기]**  
> ‘거듭제곱 연산 ^ 도 추가해 줘’라는 대화와 `^` 버튼이 추가된 계산기를 나란히 보여 주세요. 브라우저의 새로고침 버튼도 표시해 주세요.
<!-- 이미지 준비 후 위 자리표시자를 교체: ![거듭제곱을 요청하고 새로고침으로 변경을 확인한 모습](./images/07-change-result.png) -->

원하는 모습이 아니면 다시 말하면 됩니다. 예를 들어 **“버튼이 아직 작아. 조금 더 크게 해 줘”**라고 요청하세요.

## 막히면 이렇게 말하세요

혼자 해결하려고 오래 고민하지 않아도 됩니다. AI도 실수할 수 있으니, 지금 보이는 상황을 알려 주세요.

| 이런 상황이라면 | AI에게 이렇게 말해 보세요 |
| --- | --- |
| 설명이 어려워요 | “더 쉽게, 지금 할 일 하나만 알려 줘.” |
| 안내한 화면과 달라요 | “말한 화면과 달라. 어디서부터 하면 돼?” |
| 안내 파일을 못 찾는대요 | “AGENTS.md를 못 찾는 이유를 확인해 줘.” |
| 코드만 나오고 파일이 없어요 | “연습 폴더의 codes 안에 파일로 저장해 줘.” |
| 결과를 여는 방법을 모르겠어요 | “만든 파일의 위치와 여는 방법을 알려 줘.” |
| 새로고침해도 그대로예요 | “수정한 파일과 내가 열어야 할 파일의 위치를 확인해 줘.” |
| 계산 결과가 이상해요 | “2 + 3을 눌렀는데 23이 나와. 5가 나오도록 고쳐 줘.” |

마지막 예시의 숫자와 결과는 실제로 겪은 상황으로 바꿔 주세요. 파일을 다른 위치로 옮겼다면 새 위치의 파일을 다시 열어야 합니다.

## 여기까지 했다면

만족스럽다면 AI에게 **“여기까지 할게”**라고 말하세요. 만든 것과 다시 여는 방법을 정리해 줍니다.

여러분은 이미 **요청하기 → 결과 확인하기 → 수정 요청하기**를 해 본 것입니다.

결과물은 연습 폴더의 `codes`에 남습니다. 다음에도 그 안의 HTML 파일을 두 번 클릭하면 됩니다. 다른 예제를 만들고 싶다면 같은 폴더에서 AI에게 요청하세요.
