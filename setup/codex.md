# Codex로 시작하기

[공통 설치 안내로 돌아가기](./README.md)

이 안내는 **VS Code가 설치되어 있고 연습 폴더가 열린 상태**에서 시작합니다. 아직 준비하지 않았다면 [공통 안내](./README.md)를 먼저 진행하세요.

Codex는 OpenAI의 AI 코딩 도구입니다. 이 과정에서는 **VS Code 확장 프로그램과 ChatGPT 계정**을 사용합니다. 무료 요금제로 시작할 수 있지만 사용량 제한이 있으며, 로그인 없이 사용하는 방법은 아닙니다. 확인일: **2026-09-19**. [공식 요금 안내](https://learn.chatgpt.com/docs/pricing)

## A-1. ChatGPT 계정 준비하기

이미 ChatGPT 계정이 있다면 새로 만들지 않아도 됩니다. 기존 계정으로 로그인할 수 있는지 확인하고 A-2로 넘어가세요.

1. 브라우저에서 [ChatGPT](https://chatgpt.com/)를 엽니다.
2. **Sign up(가입하기)** 또는 계정 만들기 항목을 선택합니다.
3. 화면에서 제공하는 이메일 가입이나 Google·Apple·Microsoft 등의 로그인 방식 중 사용할 방식을 고릅니다. 표시되는 선택지는 달라질 수 있습니다.
4. 이메일 확인, 비밀번호 설정 등 화면에서 요청하는 가입 절차를 마칩니다. 이메일 확인이 필요하면 메일함을 열어 안내에 따릅니다.
5. ChatGPT에 로그인된 화면이 보이는지 확인합니다. 무료로 시작하려면 유료 요금제 구매는 진행하지 않아도 됩니다.

**다음에도 같은 로그인 방식을 사용하세요.** 예를 들어 Google로 가입했다면 VS Code에서 연결할 때도 같은 Google 계정을 선택합니다.

완료 확인: **브라우저에서 본인 ChatGPT 계정으로 로그인할 수 있습니다.** 브라우저 로그인만으로 VS Code 연결까지 끝난 것은 아니므로 다음 단계를 진행하세요.

> **[스크린샷 자리 · ChatGPT 가입]**  
> 가입·로그인 진입 위치와 로그인 방식 선택 화면. 개인 이메일은 가려 주세요.

## A-2. VS Code에 Codex 설치하기

1. VS Code로 돌아옵니다.
2. 왼쪽의 네모 블록 모양 **Extensions(확장)** 아이콘을 누릅니다. 찾기 어렵다면 Windows는 **Ctrl+Shift+X**, Mac은 **Cmd+Shift+X**를 누릅니다.
3. 확장 검색창에 `Codex`를 입력합니다.
4. **게시자(Publisher)가 OpenAI인 공식 Codex 확장**을 선택합니다. 비슷한 이름이 많아 헷갈리면 [공식 설치 안내](https://learn.chatgpt.com/docs/codex/ide)의 **Install the extension** 링크로 이동하세요.
5. **Install(설치)**을 누릅니다. 게시자를 신뢰할지 묻는다면 OpenAI의 공식 확장인지 확인하고 진행합니다.
6. 설치 후 재시작 또는 창 다시 불러오기를 요청하면 안내에 따릅니다.

완료 확인: **확장 상세 화면에서 설치 버튼 대신 관리 또는 제거 항목이 보입니다.**

> **[스크린샷 자리 · Codex 설치]**  
> 확장 검색창, 공식 확장 이름, OpenAI 게시자, Install 버튼을 함께 보여 주세요.

## A-3. Codex에 계정 연결하기

1. VS Code에서 **Codex 아이콘**을 눌러 대화창을 엽니다.
2. 아이콘을 찾기 어렵다면 Windows는 **Ctrl+Shift+P**, Mac은 **Cmd+Shift+P**를 누릅니다. 위쪽 검색창에 `Codex: Open Codex Sidebar`를 입력하고 해당 항목을 선택합니다.
3. Codex 창에서 **Sign in with ChatGPT(ChatGPT로 로그인)**를 선택합니다. 이 안내에서는 API 키 입력 항목을 선택하지 않습니다.
4. 브라우저가 열리면 A-1에서 준비한 계정으로 로그인합니다. 이미 로그인되어 있다면 연결할 계정이 맞는지 확인합니다.
5. 계정 연결 확인 화면이 나오면 내용을 확인하고 진행합니다. VS Code를 열지 묻는 화면이 나오면 열기를 선택합니다.
6. 로그인 완료 안내가 나타나면 VS Code로 돌아옵니다.

완료 확인: **Codex 창에 요청을 입력할 수 있습니다.** 로그인 버튼이 그대로 남아 있다면 아래 문제 해결을 확인하세요. [공식 로그인 안내](https://learn.chatgpt.com/docs/auth)

Windows에서 **Set up(설정)** 또는 **Agent sandbox 설정** 안내가 나오면 화면의 설정 절차를 진행합니다. 이는 AI가 작업할 범위를 제한하는 실행 환경입니다. 설정 중 관리자 권한이 필요하지만 사용할 수 없다면, 표시된 오류를 기기 관리자나 안내자에게 알려 주세요. [공식 Windows 실행 환경 안내](https://learn.chatgpt.com/docs/windows/windows-sandbox)

> **[스크린샷 자리 · Codex 로그인]**  
> Sign in with ChatGPT 버튼과 로그인 후 요청 입력창. 인증 코드와 계정 정보는 가려 주세요.

## A-4. 첫 대화 보내기

**브라우저의 ChatGPT 창이 아니라 VS Code의 Codex 입력창**을 클릭합니다. 아래 문장을 붙여 넣고 보내기 버튼을 누르세요.

```text
나는 코딩을 처음 배워. 한국어로 짧게 인사해 줘. 아직 파일은 만들지 마.
```

모델 선택이 보이더라도 처음에는 기본 선택을 그대로 사용하면 됩니다.

완료 확인: **VS Code의 Codex 창 안에 답변이 나타납니다.** 연결 준비가 끝났습니다. [Starter의 안내 파일 준비하기](../starter/README.md#2-ai에게-줄-안내-파일-준비하기)로 이동하세요.

> **[스크린샷 자리 · Codex 연결 확인]**  
> 연습 폴더 이름과 Codex에 보낸 첫 인사, 답변이 함께 보이는 화면.

## 잘되지 않을 때

| 상황 | 해 볼 일 |
| --- | --- |
| Codex 아이콘이 없어요 | A-3의 명령 검색 방법으로 열어 봅니다. 설치가 끝났다면 VS Code를 다시 실행해 봅니다. |
| 로그인했는데 로그인 버튼이 남아 있어요 | 브라우저의 마지막 연결 확인까지 마쳤는지 확인합니다. VS Code를 다시 열고 같은 계정으로 연결해 봅니다. |
| API 키를 입력하래요 | 로그인 선택 화면으로 돌아가 Sign in with ChatGPT를 선택합니다. |
| 인증 메일이 안 와요 | 이메일 주소와 스팸함을 확인하고, 화면에 재전송 기능이 있으면 이용합니다. |
| 사용량 한도에 도달했대요 | 안내된 사용 가능 시간을 확인하고 기다립니다. 유료 전환은 필수가 아닙니다. |
| 파일을 만들 수 없다고 해요 | 연습 폴더가 열렸는지, 초기 실행 환경 설정이 완료됐는지 확인합니다. 화면의 오류 문구를 안내자에게 알려 주세요. |

무료 제공 범위와 로그인 화면이 바뀌었다면 [공식 요금 안내](https://learn.chatgpt.com/docs/pricing), [설치 안내](https://learn.chatgpt.com/docs/codex/ide), [인증 안내](https://learn.chatgpt.com/docs/auth)를 기준으로 확인하세요.
