# 처음 시작하는 분을 위한 설치와 준비

이 안내의 목표는 **내 컴퓨터의 VS Code에서 AI에게 말을 걸고 답변을 받는 것**입니다. 코드를 입력하거나 명령어를 외울 필요는 없습니다. 한 단계씩 진행하고, ‘완료 확인’을 보고 다음 단계로 넘어가세요.

Windows와 Mac을 기준으로 설명합니다. 화면의 색상이나 버튼 이름은 설치한 버전과 언어에 따라 조금 다를 수 있습니다.

이미 VS Code에서 Codex 또는 Claude Code와 대화할 수 있다면 [Starter 실습](../starter/README.md)으로 바로 이동하세요.

## 1. 무엇을 준비하나요?

| 준비물 | 하는 일 |
| --- | --- |
| 인터넷에 연결된 컴퓨터 | 프로그램을 설치하고 AI와 대화합니다. |
| VS Code | AI와 대화하고, AI가 만든 파일을 보관하는 작업 공간입니다. |
| AI 코딩 도구 하나 | 요청에 따라 파일을 만들거나 수정합니다. Codex와 Claude Code 중 하나를 고릅니다. |
| 선택한 AI 서비스의 계정 | 본인 계정으로 로그인해 AI를 사용합니다. |
| Chrome, Edge, Safari 같은 브라우저 | 가입·로그인을 하고, 나중에 만든 웹페이지를 열어 봅니다. |

**확장 프로그램**은 VS Code에 기능을 추가하는 작은 프로그램입니다. 이 안내에서는 AI 코딩 도구를 확장 프로그램으로 설치합니다.

계정 인증 메일을 받을 수 있도록 평소 사용하는 이메일도 준비해 주세요. 이 실습을 위해 GitHub 계정을 만들거나 저장소를 내려받을 필요는 없습니다.

## 2. 사용할 AI를 하나 고르세요

두 도구를 모두 설치할 필요는 없습니다. **비용 없이 시작하고 싶다면 Codex 경로를 선택하세요.**

| 선택 | 필요한 계정과 비용 | 설치 후 읽을 안내 |
| --- | --- | --- |
| **Codex** | ChatGPT 계정. Free 요금제로 시작할 수 있으며 사용량 제한이 있습니다. | [Codex 계정 만들기와 연결](./codex.md) |
| **Claude Code** | Claude Code를 사용할 수 있는 유료 Claude 구독. 개인 사용자는 Pro 또는 Max가 해당합니다. | [Claude Code 계정 준비와 연결](./claude-code.md) |

VS Code는 무료입니다. AI 도구의 설치 비용과 AI 서비스의 이용 요금은 구분해서 생각해 주세요. Claude 무료 웹 채팅 계정만으로는 이 안내의 Claude Code 실습을 진행할 수 없습니다. 두 서비스 모두 로그인해야 하며, ChatGPT 구독과 Claude 구독은 서로 별개입니다.

이 안내는 **일반 계정으로 로그인하는 방법**을 사용합니다. API 키라는 개발자용 인증 정보를 만들거나 별도 사용량 과금을 설정할 필요는 없습니다.

요금과 이용 조건 확인일: **2026-09-19**. 조건은 바뀔 수 있으니 가입 전에 [Codex 공식 요금 안내](https://learn.chatgpt.com/docs/pricing)와 [Claude 공식 요금 안내](https://claude.com/pricing)를 확인하세요. [VS Code 공식 소개](https://code.visualstudio.com/docs/getstarted/overview)

## 3. VS Code 설치하기

이미 VS Code가 실행된다면 [4단계](#workspace)로 넘어가세요. 아래에서 자신의 컴퓨터에 해당하는 부분만 따라 하세요.

### Windows를 사용한다면

1. 브라우저에서 [VS Code 공식 다운로드 페이지](https://code.visualstudio.com/download)를 엽니다.
2. Windows용 설치 파일을 내려받습니다. 설치 종류가 여러 개라면 **User Installer**를 선택하세요. 일반적인 개인 컴퓨터 설치에 권장되는 방식입니다.
3. 다운로드가 끝나면 브라우저의 다운로드 목록 또는 파일 탐색기의 **다운로드** 폴더에서 `VSCodeUserSetup`으로 시작하는 파일을 두 번 클릭합니다.
4. 이용 약관을 읽고 동의한다면 다음으로 진행합니다. 설치 위치와 추가 옵션은 특별히 바꿀 이유가 없다면 기본값을 유지하세요.
5. **Install(설치)**을 누르고 기다립니다. 끝나면 **Finish(완료)**를 누릅니다.
6. 자동으로 열리지 않으면 시작 메뉴에서 `Visual Studio Code`를 검색해 실행합니다.

설치 파일에 `x64`와 `Arm64`가 구분되어 있고 무엇을 골라야 할지 모르겠다면, Windows의 **설정 → 시스템 → 정보 → 시스템 종류**에서 확인하세요. x64 기반이면 x64, ARM 기반이면 Arm64를 고릅니다.

완료 확인: **Visual Studio Code 창이 열리면 됩니다.** 처음 표시되는 소개 화면은 닫아도 괜찮습니다. [Windows 공식 설치 안내](https://code.visualstudio.com/docs/setup/windows)

> **[스크린샷 자리 · Windows 설치]**  
> 다운로드 페이지의 Windows User Installer 위치와 설치 후 열린 VS Code 화면. 클릭할 곳을 표시해 주세요.
<!-- 교체 예: ![Windows에서 VS Code 설치하기](./images/vscode-windows.png) -->

### Mac을 사용한다면

1. [VS Code 공식 다운로드 페이지](https://code.visualstudio.com/download)에서 Mac용 설치 파일을 내려받습니다. 칩 종류를 모르겠다면 **Universal**을 선택할 수 있습니다.
2. 다운로드한 `.dmg` 파일을 엽니다. `.zip` 파일을 받았다면 두 번 클릭해 압축을 풉니다.
3. `Visual Studio Code` 앱을 **응용 프로그램(Applications)** 폴더로 끌어다 놓습니다.
4. Finder의 **응용 프로그램** 폴더에서 `Visual Studio Code`를 두 번 클릭합니다.
5. 인터넷에서 받은 앱을 열지 묻는다면, 공식 사이트에서 받은 앱인지 확인한 뒤 **열기**를 누릅니다.

완료 확인: **Visual Studio Code 창이 열리면 됩니다.** [Mac 공식 설치 안내](https://code.visualstudio.com/docs/setup/mac)

> **[스크린샷 자리 · Mac 설치]**  
> Visual Studio Code 앱을 응용 프로그램 폴더에 넣는 화면.

## 4. 연습할 폴더 열기

AI가 만든 파일을 보관할 장소를 준비합니다. **이미 연습 폴더를 열어 두었다면 그대로 사용하세요.**

1. Windows에서는 **파일 탐색기**, Mac에서는 **Finder**를 엽니다.
2. 문서 폴더처럼 다시 찾기 쉬운 곳에 `my-first-app`이라는 새 폴더를 만듭니다. Windows에서는 빈 곳을 마우스 오른쪽 버튼으로 눌러 **새로 만들기 → 폴더**, Mac에서는 **파일 → 새로운 폴더**를 선택합니다.
3. VS Code로 돌아와 **File(파일) → Open Folder(폴더 열기)**를 누릅니다.
4. 방금 만든 `my-first-app` 폴더를 선택해 엽니다.
5. 폴더의 작성자를 신뢰하는지 묻는 창이 나오면, 방금 자신이 만든 연습 폴더가 맞는지 확인하고 신뢰를 선택합니다.

완료 확인: **VS Code 왼쪽 파일 목록에 `my-first-app`이 표시됩니다.** 안에 파일이 하나도 없어도 정상입니다. 나중에 필요한 `codes` 폴더는 AI가 만듭니다.

> **[스크린샷 자리 · 연습 폴더]**  
> VS Code 왼쪽에 열린 `my-first-app` 폴더와 폴더 신뢰 확인 화면.

## 6. 준비를 마쳤다면

다음 세 가지가 되면 준비 완료입니다.

- VS Code가 열려 있습니다.
- 왼쪽에 연습 폴더가 보입니다.
- 선택한 AI의 대화창에서 보낸 말에 답변이 옵니다.

이제 [Starter: AI와 첫 프로그램 만들기](../starter/README.md)로 이동하세요. **연습 폴더는 이미 열었으므로 Starter의 2단계 ‘AI에게 줄 안내 파일 준비하기’부터** 진행하면 됩니다. 설치 확인용 인사에 답변이 오는 것은 연결 확인이며, 실제 파일 생성은 Starter에서 확인합니다.

## 설치 도중 막혔다면

AI 연결 전에는 이 프로젝트의 안내자나 도움을 줄 사람에게 아래처럼 알려 주세요.

```text
Windows를 사용하고 있어요.
Codex 설치 안내의 A-3에서 멈췄어요.
로그인은 끝났는데 VS Code에는 아직 로그인 버튼이 보여요.
```

자신의 컴퓨터, 선택한 도구, 멈춘 단계, 화면에 보이는 문구를 적으면 됩니다. 비밀번호나 인증 코드는 보내지 마세요.

| 상황 | 먼저 해 볼 일 |
| --- | --- |
| 내려받은 설치 파일을 못 찾겠어요 | 컴퓨터의 다운로드 폴더를 열어 봅니다. |
| 회사·학교 컴퓨터에서 설치가 차단돼요 | 기기 관리자에게 설치 가능 여부를 문의합니다. |
| 화면이 영어라 어려워요 | 이 안내에서 함께 적은 영어 버튼명을 찾아봅니다. |
| AI 설치 후 아이콘이 안 보여요 | VS Code를 닫았다가 다시 열고, 연습 폴더를 엽니다. |
| 화면이 안내와 달라요 | 선택한 도구 안내의 공식 문서 링크를 확인하거나, 보이는 문구를 도움을 줄 사람에게 전달합니다. |
