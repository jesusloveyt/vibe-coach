# Calculator: 숫자를 채우며 계산기 완성하기

AI가 만든 계산기의 버튼에는 숫자 대신 `?`가 표시됩니다. 여러분은 파일에서 `?`를 숫자로 바꾸고, 저장한 내용이 화면에 나타나는 것을 확인합니다. 계산하는 코드는 AI가 준비하므로 프로그래밍 문법을 미리 공부할 필요는 없습니다.

**목표는 파일의 일부 내용을 직접 수정하고, AI에게 검토를 요청하고, 실행 결과를 확인하는 경험입니다.**

기본 실습을 마친 뒤에는 원하는 분만 JavaScript 계산 로직을 직접 수정해 볼 수 있습니다. 덧셈과 뺄셈은 자세한 안내를 받고, 곱셈과 나눗셈은 직접 작성한 뒤 리뷰를 받습니다.

## 준비하기

VS Code에서 작업 폴더를 열고, 파일을 읽고 수정할 수 있는 AI 코딩 도구와 대화할 수 있으면 시작할 수 있습니다. 준비가 필요하다면 [설치 안내](../../setup/README.md)를 참고하세요. Starter 수료는 필수가 아닙니다.

GitHub 계정, 저장소 복제, Node.js, 데이터베이스는 필요하지 않습니다. 계산기는 브라우저에서 파일을 직접 열어 사용합니다. 별도 서비스 비용은 없으며, AI 도구의 이용 요금이나 사용량 제한은 사용하는 서비스에 따릅니다.

## 1. 코칭 지침 전달하기

[AGENTS.md](./AGENTS.md)의 본문 전체를 복사하여 현재 작업 폴더의 `AGENTS.md` 파일에 붙여넣고 저장하세요. 기존 지침이 있다면 내용을 먼저 확인하고, 보관할 내용은 별도로 복사해 두세요.

AI 대화창에 다음을 입력합니다.

```text
현재 폴더의 AGENTS.md를 읽고 계산기 실습을 안내해 줘.
나는 코딩 초보자야. 버튼의 ?를 숫자로 바꾸는 작업은 내가 직접 해 볼게.
```

이미 이 저장소를 열어 둔 경우에는 파일을 복사하지 않고 “solutions/calculator/AGENTS.md를 읽고 계산기 실습을 안내해 줘”라고 요청해도 됩니다.

## 2. 물음표가 있는 계산기 열기

AI가 현재 작업 폴더 아래 `codes/calculator.html`을 만듭니다. 같은 이름의 기존 계산기가 있으면 AI가 확인 후 다른 파일명을 사용하거나 이어서 작업합니다.

파일 탐색기에서 AI가 알려 준 파일을 두 번 클릭해 브라우저로 여세요. 다른 프로그램으로 열리면 **연결 프로그램**에서 브라우저를 선택합니다.

숫자 버튼에 `?`가 보이는 것은 이번 실습을 위해 준비된 상태입니다. 연산 버튼과 계산 기능은 AI가 미리 만들어 둡니다.

## 3. 숫자를 직접 채우기

VS Code에서 AI가 알려 준 파일을 엽니다. AI가 실제 줄 번호와 찾을 문구, 각 위치에 넣을 숫자를 안내합니다.

아래는 수정 방식의 예시입니다. 실제 파일에서는 AI가 안내한 위치를 따라가세요.

수정 전:

```html
<button type="button" data-digit="7" aria-label="숫자 7">?</button>
```

수정 후:

```html
<button type="button" data-digit="7" aria-label="숫자 7">7</button>
```

지금은 `>`와 `<` 사이의 `?`만 숫자로 바꾸면 됩니다. 따옴표나 다른 부분은 수정하지 않아도 됩니다. 한 버튼을 먼저 바꿔 저장하고 브라우저를 새로고침하면 변화를 확인할 수 있습니다.

이어서 나머지 숫자 버튼도 채웁니다. 파일 전체의 물음표를 한꺼번에 바꾸지 말고 안내받은 버튼을 하나씩 수정하세요. 저장은 Windows에서 `Ctrl+S`, macOS에서 `Cmd+S`입니다.

## 4. AI에게 검토 요청하기

저장한 뒤 다음처럼 입력하세요.

```text
검토 요청. 숫자 버튼의 ?를 모두 채우고 저장했어.
표시한 숫자가 각 버튼에 맞는지 확인해 줘.
```

AI가 파일을 읽고 확인합니다. 고칠 부분이 있으면 위치와 이유를 설명하고 “변경할까요?”라고 묻습니다. “예” 또는 “수정해 줘”라고 하면 AI가 수정합니다. “내가 다시 해 볼게”라고 하면 직접 고칠 수 있도록 기다려 줍니다.

AI의 설명이 어렵거나 화면과 다르면 “더 쉽게 설명해 줘” 또는 “말한 화면과 달라”라고 알려 주세요. AI도 실수할 수 있습니다.

## 5. 계산해 보고 개선하기

브라우저를 새로고침하고 숫자 버튼이 제대로 표시되는지 확인하세요. **초기화 → 2 → + → 3 → =**를 눌러 결과가 `5`인지 확인하고 AI에게 알려 주세요.

덧셈이 잘 나오면 다음 단계인 화면이나 기능 개선으로 넘어갑니다. 나머지 테스트는 원할 때 직접 해 보시면 됩니다. 아래는 자율 테스트 예시이며, 매 계산 전에 **초기화**를 누르세요. 결과를 하나씩 AI에게 보고할 필요는 없고, 문제가 있으면 알려 주세요.

| 입력 | 기대한 결과 |
| --- | --- |
| `9 − 4 =` | `5` |
| `6 × 7 =` | `42` |
| `8 ÷ 2 =` | `4` |
| `1.5 + 2 =` | `3.5` |
| `8 ÷ 0 =` | 계산할 수 없다는 안내 |

원하는 변화가 있으면 “숫자 버튼을 더 크게 해 줘”처럼 요청하세요. AI는 도움이 되는 순간에 더 명확한 프롬프트 예시와 이유도 짧게 알려 줍니다. 제안 문장을 다시 입력할 필요는 없으며, “프롬프트 조언은 생략해 줘”라고 할 수도 있습니다.

## 6. 선택: 계산 로직 수정하기

기본 실습과 요청한 개선이 끝나면 AI가 **“로직을 수정하는 연습을 진행하시겠습니까?”**라고 묻습니다. “예”라고 하면 이어서 진행하고, “아니요”라고 하면 기본 실습을 마칩니다. 바로 끝내고 싶다면 “종결” 또는 “여기까지 할게”라고 말해도 됩니다.

참여하면 AI가 완성본을 별도 파일로 보관한 뒤 실습 파일의 JavaScript 사칙 연산 기능을 잠시 비활성화합니다. 숫자와 버튼 화면은 유지되며, 아직 복원하지 않은 연산에는 “아직 구현하지 않은 연산입니다”라는 안내가 나옵니다.

| 순서 | 실습 방법 |
| --- | --- |
| 덧셈 `+` | AI가 수정 위치, 변경 전후 코드, 의미를 자세히 안내합니다. 직접 입력하고 `2 + 3 = 5`를 확인합니다. |
| 뺄셈 `-` | 같은 방식으로 안내받아 수정하고 `9 - 4 = 5`를 확인합니다. |
| 곱셈 `*`와 나눗셈 `/` | 앞의 두 예시를 참고해 직접 수정합니다. 위치와 연산 기호는 AI가 알려 줍니다. |
| 리뷰 | 저장한 뒤 “로직 검토 요청”이라고 입력합니다. AI가 코드를 읽고 계산 방식과 동작을 검토합니다. |

이 단계에서는 계산 결과를 돌려주는 짧은 코드를 다룹니다. 필요한 의미는 그때 설명하므로 문법을 따로 공부하고 올 필요는 없습니다. 화면의 `×`, `÷`는 JavaScript 계산식에서 각각 `*`, `/`로 표현합니다. 숫자 입력 처리와 0으로 나누기 처리는 AI가 준비해 둡니다.

직접 구현한 뒤에는 `6 × 7 = 42`, `8 ÷ 2 = 4` 등을 확인해 보세요. 오류가 있으면 AI가 위치와 이유를 설명하고 다시 수정할 기회를 줍니다. 막히면 힌트를 요청하거나 “수정해 줘”라고 도움을 받을 수 있습니다.

중간에 끝내도 괜찮습니다. AI가 아직 구현하지 않은 연산과 이어서 할 파일을 알려 줍니다. 완성된 계산기가 필요하면 AI가 별도로 보관한 완성본을 열면 됩니다.

## 막혔을 때

- **수정할 줄을 못 찾겠다면:** “지금 파일에서 찾을 문구와 바꿀 위치를 다시 알려 줘”라고 요청하세요. 편집하면서 줄 번호가 달라질 수 있습니다.
- **화면이 그대로라면:** 파일을 저장하고 브라우저를 새로고침하세요. AI가 안내한 파일을 열었는지도 확인하세요.
- **파일을 잘못 바꿨다면:** “검토 요청. 버튼을 수정하다가 화면이 이상해졌어”라고 알려 주세요. AI가 파일을 확인하고 수정 방법을 안내합니다.
- **계산 결과가 다르다면:** 누른 숫자와 연산, 실제 결과를 알려 주세요. 예: “2 + 3을 눌렀는데 6이 나와. 5가 나오도록 확인해 줘.”

전체 진행 모습은 [대화 예시](./dialogues.md)에서 볼 수 있습니다.
